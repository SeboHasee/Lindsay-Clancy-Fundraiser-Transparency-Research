# Methodology

Pipeline:

SOURCE -> OBSERVATION -> EVIDENCE -> VALIDATION -> ANALYSIS -> PUBLICATION

The system enforces provenance and preserves original observed values before normalization.

Update flow:
1. Monitor source metadata and content fingerprints.
2. Preserve observations and evidence references.
3. Validate records and detect conflicts.
4. Route risky changes to review queue.
5. Regenerate statistics, coverage, and reports.
6. Apply publication filter and privacy scan before public export.
